**Finding, a Quirk needs a scope.** Reported from a concurrent recorder session. The ChangeCube quirk holds on the loose-clock `--load` path; under `--fixed-dt` the seed is 0 and deterministic, and a code comment about that configuration reads as contradicting the quirk until the two scopes are stated. This engine forks behaviour on `--load` against fresh start, pinned against host clock, and headless against windowed, so an unscoped Quirk is a wrong belief waiting for a reader to resolve the contradiction by deleting one side. Both Quirks in this slice carry a producer key `scope`; the profile should require it.

**Finding, negative space.** Same source. Three format errors in one session were each an assumption that a header field says more than it does: `engine=` is not a build identity, `mode.fixed_dt` says that the step was pinned and not when, and a torn poll stream is not detectable the way a torn chunk is. A Format that records every guarantee and none of the traps is worse than the source comments it summarises. The `.rec` Format carries a "What it does not tell you" section; the profile should make it a required body section on Format, and probably on Subsystem.

**Finding, provenance on a moving subsystem.** Same source. The recorder changed in the day this slice was written (#661 merged, two branches unpushed, a `--replay` crash being fixed), so a Subsystem or Format concept about it is current only at a commit. Both carry a producer key `as_of` naming the commit their details were read from. The profile should require it on concepts about subsystems under active change, and should say which claims in a concept are structural and which are current, since a concept that mixes them without dating is worse than grep, which at least dates itself by what is in the tree.

**Finding, one mechanism, several manifestations.** Same source. One fact (`RestoreTimer` rewinds `TimerRefHR` and not `LastTime`, so restoring one of a coupled pair is not a rewind) was rediscovered three times in one night as a proposed mechanism, a dismissed hazard and the actual blocker, by two people who had both written it down. A typed relation for "same mechanism, different manifestation" would have caught it; no instance exists in this slice, so the key is proposed here and not defined.
